# Daily 404/500 — przeglądy projektu

Kierunek wybrany przez użytkownika: **02 — Geometria Daily**. Każdy przegląd wykonuje nowy agent `gpt-6.1-sol`, `reasoning_effort: high`, bez historii rozmowy. Agent dostaje wyłącznie ścieżkę zrzutu i [stały prompt](critic-prompt.txt). Prompt nie zawiera progu akceptacji. Każdy kolejny przegląd dotyczy zmienionego projektu.

[Galeria wszystkich 85 wersji z oceną powyżej 8/10](above-8-offline.html) · [lista z ocenami](above-8.md). Galeria offline zawiera wszystkie obrazy, filtry i powiększanie.

Pierwsze przeglądy obejmowały planszę obu stanów. Iteracje 12–44 pokazują pojedynczy stan w pełnym oknie 1280 × 800. Iteracje 45–140 pokazują wspólny zestaw 404 i 500. Iteracje 141–176 dotyczą pojedynczego 404. Iteracje 177–196 pokazują oba rzeczywiste widoki aplikacji w oknie 1280 × 800, zapisane jako zrzut całej trasy. Od iteracji 197 oceniany jest ponownie pojedynczy stan 404. Od iteracji 210 zrzuty pokazują pełne okno laptopa 1280 × 720. Kompozycja rozwija moduły znaku Daily. Podgląd aplikacji pozwala wyświetlić oba stany razem lub osobno przez parametr `?status=404` / `?status=500`.
